# Noni's DIY Auction Helper

Version 0.7.23 of the auction helper for E-Hentai forum auction threads.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser and complete its browser setup instructions.
2. Open [Install Noni's DIY Auction Helper](https://raw.githubusercontent.com/TetsuOrb/nonis-diy-auction-helper/main/auction-helper.user.js).
3. Confirm **Install** in Tampermonkey, then open or reload an auction thread.

If the link displays source text, check that Tampermonkey is enabled and allowed to run userscripts in your browser, then reopen the link.

## Updates

The installation link stays the same for future versions. The script's `@updateURL` and `@downloadURL` both point to that file; Tampermonkey can check it for updates. Future releases must increase `@version` and replace the same file on `main`.
